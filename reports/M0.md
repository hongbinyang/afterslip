## Findings and limitations

- **Simulator state alone is not a snapshot.** Restoring only `sim.get_state()` diverges from the first replayed step (max abs difference ≈ 0.037). The full snapshot also needs MuJoCo's integration state (including the solver warm-start), the arm controller's and gripper's Python-side state, the step counters and the global NumPy RNG. The simulator-state-only test is kept as an expected failure to document this.
- **Global RNG:** robosuite samples with NumPy's global RNG, so several environments in one process share it; snapshots are exact for one environment per process (design §4.4).
- **Snapshot scope:** in memory, same backend. Serialization and hashing follow in M2 (2.1, T2.1).
- **Linux system libraries** are required outside the locks: a C toolchain and CMake (to build `egl-probe`), OSMesa, GLib (setup.md §6.2).
- **Not yet verified:** native x86-64 hardware and GitHub Actions (first CI run pending); EGL/GPU rendering; any pretrained policy (0.2b, 0.3).
